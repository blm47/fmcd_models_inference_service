# Модельные классы INVEST

Место для исходников моделей и связанных с ними модулей INVEST.
Для многофайловой модели создаётся отдельный подпакет. Preprocessing и логика
применения располагаются рядом с pipeline в каталоге backend, веса и обученные
статистики — в `artifacts_dir`.

Исходный код и артефакты INVEST пока не предоставлены; pipeline остаётся заглушкой.
