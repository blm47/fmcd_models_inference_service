# Пакет моделистов FMCD

Разместите здесь **содержимое** прежнего корневого каталога `fmcd/` из рабочего
сервиса, включая `__init__.py`, `data/`, `model/` и остальные зависимые модули.
В данном workspace исходников нет, поэтому перенесено только место для них;
фиктивные классы модели не создаются.

Классы моделей остаются внутри `model/`, вспомогательные классы и код — в своих
подпакетах. Пакет должен быть самодостаточным относительно остальных движков.

Используется только пакет `app.models.backends.fmcd_cc_dc.utils.fmcd`.
Внутри исходников применяйте относительные импорты или полные пути этого пакета.
Например, импорт `from fmcd.data.base import FMCDBatch` заменяется относительным
импортом в зависимости от расположения модуля. Регистрации старого имени `fmcd`,
подмены sys.modules и переходного загрузчика нет.

Артефакты должны быть подготовлены для новой структуры классов. Сервис разворачивается
на препроде с нуля; совместимость с checkpoint старой архитектуры не реализуется.

Код пакета остаётся импортированным между задачами. Он не должен хранить веса,
обученные encoder или другие ресурсы pipeline в глобальных переменных: ими владеет
экземпляр `FMCDCardsRunner`, который освобождает их в close.
